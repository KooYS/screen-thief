# 화면 도둑 (screen-thief)

단축키 한 번으로 보던 탭을 숨기고 Slack 탭으로 넘어가는 크롬 확장.

- `⌥ + S` (Alt+S): 현재 탭을 접힌 탭 그룹(`PR 리뷰`)에 숨기고 `app.slack.com` 탭을 활성화
- 다시 `⌥ + S`: 그룹을 풀고 숨겼던 탭으로 복귀

탭을 닫지 않고 그룹으로 접기만 하므로 새로고침이 일어나지 않고, 입력하던 내용도 그대로 남습니다.

## 설치

1. 이 레포를 클론
2. `chrome://extensions` → 개발자 모드 켜기 → **압축해제된 확장 프로그램 로드** → 클론한 폴더 선택
3. `chrome://extensions/shortcuts`에서 단축키가 지정됐는지 확인 (다른 확장과 겹치면 비어 있을 수 있음)

## 설정

그룹 이름은 `background.js` 맨 위의 `GROUP_TITLE`을 바꾸면 됩니다.

## 한계

- 크롬은 탭 숨김 API가 없어서, 탭 바에 그룹 칩이 남습니다. 칩에 마우스를 올리면 탭 제목 미리보기가 보일 수 있습니다.
- 한 번에 탭 하나만 숨깁니다.
