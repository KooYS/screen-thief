# 화면 도둑 (screen-thief) 설계

## 목적

회사 자리에서 이직 준비(원티드, 리멤버, 내 포트폴리오 페이지)를 할 때, 지나가는 사람이 보면 **업무용 Slack 채널을 읽는 화면**으로 보이게 하는 크롬 확장.

## 사용 흐름

1. 아무 페이지에서 단축키 `⌥ + S` (Alt+S)
2. 페이지 본문을 추출해 화면 전체를 Slack 웹 레이아웃 오버레이로 덮음
3. 탭 제목 → `<채널명> (Channel) - Slack`, 파비콘 → Slack 파비콘
4. 같은 단축키를 다시 누르면 원래 화면으로 복원 (스크롤 위치·입력 내용·로그인 유지)

원래 페이지는 숨기기만 하고 DOM을 수정하지 않는다. 클릭·입력 같은 조작은 원래 화면에서 한다.

## 렌더링 규칙

- **상세 페이지** (공고 상세, 포트폴리오 글): 본문 블록을 `h1~h3` 기준으로 섹션 분할. 첫 섹션 = 채널 메시지, 나머지 섹션 = 그 메시지의 스레드 답글.
- **목록 페이지** (공고 목록, 검색 결과): 본문 블록의 링크 텍스트 합이 전체 텍스트의 60% 이상이면 목록으로 판단. 링크 하나 = 메시지 하나.
- **본문 블록 선택**: `main` 또는 `article`이 있으면 그것, 없으면 `body` 하위 요소 중 `innerText` 길이가 가장 긴 블록.
- **작성자**: 설정의 동료 이름 목록에서 메시지마다 순환 배정. 시각은 현재 시각 기준으로 몇 분씩 거슬러 생성.
- **단어 치환**: 모든 렌더 텍스트에 치환 사전 적용. 기본값: `연봉→단가`, `지원하기→반영 요청`, `지원→반영`, `채용→배포`, `이력서→명세서`, `포트폴리오→릴리즈 노트`, `면접→리뷰`, `합격→머지`.

## 설정 (options 페이지)

| 항목 | 기본값 |
|---|---|
| 현재 채널명 | `fe-dev` |
| 사이드바 채널 목록 | `general, fe-dev, deploy, incident` |
| 동료 이름 목록 | `김민수, 이지은, 박준호` |
| 치환 사전 | 위 기본값 (한 줄에 `원래=바꿀말`) |

`chrome.storage.sync`에 저장. 외부 네트워크 요청 없음.

## 파일 구성

빌드 도구·의존성 없음. Manifest V3.

```
manifest.json    # 권한: storage. content script를 <all_urls>에 주입
content.js       # 단축키 감지, 본문 추출, 오버레이 렌더, 복원
words.js         # replaceWords(text, dict) 순수 함수
overlay.css      # Slack 레이아웃. 모든 셀렉터는 #st-overlay 하위로 한정
options.html
options.js
words.test.js    # node --test
```

## 결정과 이유

- **단축키는 content script keydown 리스너**: `chrome.commands`는 서비스 워커가 필요함. 페이지 포커스가 있을 때만 동작하지만 실사용엔 충분.
- **본문 추출은 휴리스틱**: Readability 같은 라이브러리를 넣지 않음. 원티드·리멤버에서 부족하면 그때 사이트별 셀렉터를 추가.
- **오버레이 방식**: 사이트별 CSS를 덮어쓰지 않으므로 어떤 사이트든 같은 코드로 동작.

## 범위 밖 (v1)

오버레이 안에서 클릭·입력, 사이트별 맞춤 레이아웃, 사람 접근 자동 감지, 보스키(창 전환).

## 검증

- `node --test`: 단어 치환 (긴 단어 우선 치환, 빈 사전, 반복 등장)
- 수동: 원티드 공고 상세, 원티드 목록, 리멤버 공고, 내 포트폴리오 페이지에서 토글 → Slack 화면 확인 → 복원 후 스크롤·입력 유지 확인
